# Specification

## Summary
**Goal:** Transform the application into QubeYards, a comprehensive real estate platform with buy/sell/rent transactions, pan-India coverage, admin-controlled property approvals, news section, and partner currency rewards.

**Planned changes:**
- Add transaction types (buy, sell, rent) to property listings
- Enable pan-India location support for properties
- Add offers display section on main dashboard
- Implement project stage categories (pre-launch, launch, ready-to-shift)
- Create admin role system with approval and edit permissions
- Add property approval workflow requiring admin approval before listing goes live
- Create news and magazine section for real estate content
- Implement QubeYards currency reward system for partners
- Display currency balance in partner dashboard
- Restrict partner features to authenticated partner role users
- Update branding to QubeYards throughout the application
- Apply modern, premium visual design with teal, gold, and white color scheme

**User-visible outcome:** Users can browse buy/sell/rent properties across India filtered by project stage, view promotional offers, read real estate news, and partners can list properties to earn QubeYards currency visible in their dashboard, with all new listings pending admin approval.
